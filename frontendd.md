## 🎮 Game Overview

Brain Bank Heist is an interactive educational web game where players
take on the role of a thief attempting to crack a secure vault. To
succeed, players must correctly answer multiple-choice questions across
three difficulty levels: Easy, Medium, and Hard.


### ⚙️ How the Game Works (Frontend)

-   Select "Brain Bank Heist" from the homepage
-   Answer quiz questions to progress through layers
-   Difficulty levels:
    -   Easy
    -   Medium
    -   Hard

### ❗ Two-Strike Rule

-   First wrong answer → Retry allowed
-   Second wrong answer → Game Over

## 🏆 Winning the Game

-   Answer all questions correctly
-   Reach the results page and crack the vault

## 💥 Losing the Game

-   Two incorrect attempts end the game

## 📊 Results Page

-   View final score
-   Replay the game 
-   Return to the homepage and choose another game or another subject
